# Freelance adapter fixtures

Файлы в `backend/tests/fixtures/freelance/` — минимальные офлайн-снимки структуры
публичных ответов источников для тестов парсеров. Это не рабочая база CRM и не
содержит cookies, токенов, личных страниц или результатов пользователя.

Live-проверка выполняется отдельно: публичные адаптеры получают текущую ленту,
а закрытые источники используют локальный Chromium-профиль после ручной
авторизации. CAPTCHA и защитные ограничения не обходятся.
