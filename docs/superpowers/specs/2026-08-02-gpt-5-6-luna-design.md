# GPT-5.6 Luna in Semix CRM — Design

## Goal

Сделать `GPT-5.6 Luna` доступной моделью для всех существующих AI-функций
Semix CRM, включая проверку подключения и генерацию сообщений в разделе
«Волк с Уолл-стрит».

## Verified provider contract

- Официальный идентификатор модели: `gpt-5.6-luna`.
- Документация OpenCode относит модель к Zen и указывает Responses endpoint.
- Актуальный каталог `https://opencode.ai/zen/go/v1/models` уже возвращает Luna.
- Живой запрос с сохранённым OpenCode Go ключом к существующему endpoint CRM
  `/zen/go/v1/chat/completions` вернул HTTP 200 и текстовый ответ.
- Живой запрос с `response_format: {"type": "json_object"}` вернул валидный JSON.

Следовательно, для текущей конфигурации не требуется миграция на Responses API:
Luna совместима с уже используемым клиентом `AiClient`.

## Architecture

`backend/ai/settings.py` остаётся единственным источником разрешённых моделей.
В `SUPPORTED_MODELS` первой записью добавляется
`("gpt-5.6-luna", "GPT-5.6 Luna")`. API настроек автоматически отдаёт новую
модель фронтенду, а существующий `<select>` показывает её без отдельной логики.

Схема SQLite, формат настроек, ключ и endpoint не меняются. Сохранённый ключ
остаётся локальным. Текущая выбранная модель не переключается миграцией, но после
публикации CRM будет явно переведена на Luna через существующий API настроек с
сохранением текущего ключа и таймаута.

## Connection check

Короткий лимит `max_tokens=8` недостаточен для reasoning-моделей: Luna может
вернуть HTTP 200 без итогового текста, потратив лимит до финального ответа.
Проверка подключения будет использовать `max_tokens=128`. Обычная генерация уже
использует лимит 1600 и не требует изменений.

## UI

Новая модель появляется в существующем поле «Модель» в настройках. Подсказка
меняется с узкого текста про модели Go `chat/completions` на точное описание:
«Доступные модели OpenCode, проверенные с текущим API Semix CRM».
Новых экранов и элементов управления не требуется.

## Error handling

Сохраняются текущие сообщения для HTTP 401, 429, сетевых ошибок и пустого ответа.
Если провайдер позже уберёт Luna из Go endpoint, кнопка «Проверить подключение»
покажет фактическую ошибку и не сохранит ключ автоматически.

## Tests and delivery

- Backend RED→GREEN: Luna присутствует в безопасных настройках, принимается при
  сохранении и проверяется с лимитом 128 токенов.
- Frontend RED→GREEN: Luna отображается и может быть выбрана и сохранена.
- Полный frontend/backend test suite и production build.
- Живая проверка настройки и текстового/JSON ответа Luna.
- Обновление README, коммит и push напрямую в `main` согласно постоянной установке
  пользователя для этого проекта.
