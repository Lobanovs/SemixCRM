# Автономный runtime parser-2gis

## Проблема

Текущая интеграция `backend/parser.py` зависит от двух абсолютных каталогов за пределами SemixCRM: `LeadHunt/_external/parser-2gis` и `parser2gic/parse_runner.py`. В чистом клоне их нет, поэтому сбор останавливается с `FileNotFoundError` ещё до открытия 2ГИС.

Upstream-проект `interlark/parser-2gis` версии 1.2.1 принимает все уже используемые SemixCRM CLI-параметры и пишет совместимый JSON. Устанавливать его в `backend/.venv` нельзя: upstream требует Pydantic 1.x, а FastAPI-часть SemixCRM работает на Pydantic 2.x. Кроме того, реальная проверка показала, что 2ГИС отдаёт CAPTCHA headless-браузеру, тогда как headed Chrome успешно собирает карточки.

## Выбранное решение

SemixCRM создаёт отдельное виртуальное окружение в игнорируемом каталоге `backend/data/parser2gis-runtime`, устанавливает туда закреплённый `parser-2gis==1.2.1` при первом запуске и вызывает точку входа пакета через Python этого окружения. Установка выполняется только при отсутствии импортируемого пакета и защищается блокировкой от одновременного запуска нескольких задач.

`collect_2gis()` больше не проверяет каталоги `LeadHunt` и `parser2gic`, не меняет `PYTHONPATH` и не запускает `parse_runner.py`. Он получает команду от отдельного модуля runtime, передаёт официальный CLI URL поиска, лимит и JSON-файл, а затем использует существующую нормализацию карточек.

## Конфигурация

- `PARSER2GIS_RUNTIME_DIR` меняет каталог изолированного окружения.
- `PARSER2GIS_PYTHON` позволяет использовать заранее подготовленный Python с установленным `parser-2gis` и отключает автоматическое создание окружения.
- `PARSER2GIS_HEADLESS` управляет режимом Chrome; значение по умолчанию — `no`.
- Старый `LEADHUNT_HEADLESS` сохраняется только как fallback для обратной совместимости.

## Ошибки и статусы

Во время первой установки пользователь получает статус об инициализации движка. Ошибка создания venv, установки пакета, запуска CLI, таймаут или пустой JSON превращаются в понятную ошибку задачи парсинга. Пустой результат отдельно подсказывает про возможную CAPTCHA и необходимость headed-режима.

## Проверка

1. Регрессионный тест доказывает, что команда 2ГИС строится через runtime и больше не требует внешних путей.
2. Модульные тесты проверяют готовое окружение, первую установку и пользовательский Python.
3. Полный набор backend-тестов и frontend-сборка должны пройти.
4. Реальный вызов `collect_2gis()` должен вернуть хотя бы одну карточку с названием и контактными данными из 2ГИС.

## Рассмотренные альтернативы

- Хранить fork upstream внутри SemixCRM: увеличивает объём поддержки и добавляет LGPL-код без необходимости.
- Оставить ручной `parser2gic`: сохраняет исходную причину поломки и делает чистый клон нерабочим.
- Ставить upstream в `backend/.venv`: создаёт несовместимость Pydantic 1.x и 2.x.
