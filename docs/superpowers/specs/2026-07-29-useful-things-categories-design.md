# Категории «Полезных вещей»

## Цель

Превратить раздел «Полезные вещи» из списка ссылок в единый рабочий каталог,
где записи можно переключать по вкладкам: «Все», «Промпты», «Сайты»,
«Магазины», «Статьи» и «Другое».

## Выбранный подход

Все виды записей остаются в существующей таблице `useful_links` и используют
прежний CRUD API. К записи добавляется поле `category` со значениями:

- `prompt`;
- `website`;
- `shop`;
- `article`;
- `other`.

Существующие записи автоматически мигрируют в категорию `website`. Это сохраняет
данные пользователя и не создаёт параллельные API и таблицы.

## Данные и валидация

Общие поля: название, категория, описание, дата создания и дата обновления.

- Для `prompt` адрес необязателен, а описание содержит обязательный текст промпта
  длиной до 5000 символов.
- Для остальных категорий адрес обязателен, нормализуется до HTTP(S) URL и остаётся
  уникальным. Описание необязательно и ограничено 1000 символами.
- Неизвестная категория отклоняется с понятной ошибкой.
- Старый API-клиент без `category` продолжает создавать запись категории `website`.

Таблица мигрирует с обязательного уникального `url` на пустой адрес для промптов и
частичный уникальный индекс только для непустых URL.

## Интерфейс

Под заголовком страницы размещается горизонтальная панель вкладок. Каждая вкладка
содержит Lucide-иконку, название и число записей. Активное состояние использует
синий фон/контур Semix CRM и не обозначается одним цветом: дополнительно применяется
`aria-pressed`.

Поиск фильтрует только выбранную категорию. «Все» показывает общий каталог.
Счётчики вычисляются из уже загруженных данных без дополнительных API-запросов.

Форма начинается с выбора категории:

- у промпта скрывается адрес, описание переименовывается в «Текст промпта» и
  становится обязательным;
- у остальных типов показываются адрес и описание;
- подписи, подсказки и текст кнопки соответствуют выбранному типу.

Карточка показывает бейдж категории. Для ссылочных записей основное действие —
«Открыть», для промпта — «Копировать». Редактирование и удаление остаются доступными
для всех типов.

## Состояния и доступность

- загрузка, ошибка, пустой каталог и пустая выбранная категория имеют отдельные
  понятные состояния;
- кнопки не меньше 44×44 px, имеют доступные имена и видимый focus;
- вкладки доступны с клавиатуры, состояние передаётся через `aria-pressed`;
- копирование сообщает об успехе через `role="status"` и об ошибке через
  `role="alert"`;
- анимации укладываются в 150–200 ms и отключаются через
  `prefers-reduced-motion`.

## Проверка

Backend-тесты покрывают миграцию старой схемы, категории, промпты без URL,
валидацию и обратную совместимость API. Frontend-тесты покрывают вкладки и
счётчики, комбинированный поиск, создание промпта, копирование, сохранение
категории при редактировании и существующий CRUD ссылок. После автоматических
тестов выполняется живая проверка добавления, фильтрации, копирования,
редактирования и удаления временных записей.
