# GPT-5.6 Luna Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить `GPT-5.6 Luna` в AI-настройки Semix CRM и сделать её активной моделью для существующей генерации.

**Architecture:** Реестр поддерживаемых моделей backend расширяется идентификатором `gpt-5.6-luna`; API уже передаёт этот реестр React-интерфейсу. Существующий OpenAI-compatible клиент и Go endpoint сохраняются, потому что текстовый и JSON-запросы Luna с текущим ключом проверены живым HTTP 200.

**Tech Stack:** Python 3.13, FastAPI, httpx, SQLite, React, TypeScript, unittest, Vitest, Testing Library.

## Global Constraints

- Model ID: `gpt-5.6-luna`.
- Display label: `GPT-5.6 Luna`.
- Endpoint остаётся `https://opencode.ai/zen/go/v1/chat/completions`.
- Сохранённый API-ключ нельзя выводить в тесты, логи или ответы API.
- Проверка подключения использует `max_tokens=128`, обычная генерация — текущие лимиты.
- Никаких изменений схемы SQLite и никаких новых зависимостей.
- Изменения коммитятся и отправляются напрямую в `main`.
